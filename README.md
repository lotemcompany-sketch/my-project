# BeatCut — עריכת סרטוני ריקוד לפי הביט

כלי שמקבל שיר + קליפים גולמיים של ריקוד/הרמות, בוחר את הרגעים החזקים ביותר וחותך אותם בדיוק על הביטים, עם דשבורד לצפייה ועריכה.

## התקנה
```bash
pip install -r requirements.txt   # + ffmpeg מותקן במערכת
```

## שימוש
```bash
# 1. ניתוח ובניית טיימליין אוטומטי
python -m beatcut auto --song song.mp3 --clips ./clips --out ./projects/reel1

# 2. דשבורד לעריכה (http://localhost:8765)
python -m beatcut dashboard ./projects/reel1

# 3. (אופציונלי) ללמוד את הסגנון שלך מסרטונים שערכת בעבר
python -m beatcut learn old_reel1.mp4 old_reel2.mp4 --out templates/my_style.json
python -m beatcut auto --song song.mp3 --clips ./clips --out ./projects/reel2 --template templates/my_style.json
```

## פריסטים
- `--template dance` (ברירת מחדל): חיתוכים נקיים, הרמות נכנסות 0.8 שנ׳ לפני השיא כדי שיראו את הכניסה.
- `--template sport`: לסרטוני אימון ותרגילים. כל תרגיל מחזיק 4–8 ביטים, חיתוך על החזרה החזקה, בלי חזרה על אותו קטע.
- `--length 15..45`: אורך הסרטון. הכלי בוחר לבד את הקטע הכי חזק בשיר ומעדיף שהדרופ יהיה בתחילתו.

## איך זה עובד
- **שיר** (`audio.py`): טמפו, ביטים, דאון-ביטים (תחילת תיבה), אנרגיה, חלוקה לקטעים: אומנותי / גרוב / מהיר, וזיהוי דרופים.
- **קליפים** (`video.py`): Optical-flow לתנועה, תנועה כלפי מעלה (זיהוי הרמות/קפיצות), חדות ותאורה, ומציאת "רגעים": שיאים (לחיתוך חד) וקטעים זורמים (לאומנותי).
- **תכנון** (`planner.py`): כל חיתוך מתחיל ונגמר על ביט. בקטעים מהירים חותכים כל 1–2 ביטים, בקטעים אומנותיים כל 4–8 ביטים, עם האטה קלה. ההרמה החזקה ביותר נכנסת כהוק בפתיחה ועל הדרופים, עם זום ופלאש.
- **רנדר** (`render.py`): 1080×1920 ב-30fps, מדויק לפריים, עם השיר המקורי.
- **דשבורד**: תצוגה מקדימה מסונכרנת, טיימליין עם ביטים, החלפת רגע, שינוי אורך בביטים, נקודת כניסה, מהירות, אפקטים, נעילה ו"צור מחדש".
